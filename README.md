# ISC2 AI Security Trainer

A free study aid for the ISC2 AI Security pilot exam, from A&M Strategies.

**Open the trainer:** https://galloway03.github.io/ai-security-trainer/

## What's inside
- A 10-question daily check that builds a streak
- A lesson for every subdomain, with traps and exam tips
- 500 practice questions with explanations and where to read more, down to the chapter and section where mapped
- Timed practice exams weighted like the real exam: 160 questions in 180 minutes, with no going back
- Flashcards, trap patterns, a day-by-day study plan and progress by domain

There's no sign-up. Your progress stays in your own browser and is never sent anywhere.
Use **Copy progress** and **Paste progress** on the Progress page to move it between devices.

## Found a mistake or have an idea?
Use **Report a problem with this question** under any answer, or the **Feedback** page in the app.
Both open an email to mgalloway@amstrategiesnv.com with the details filled in.

Security issues: see [SECURITY.md](SECURITY.md).

## Please note
This is an independent study aid built from the public exam outline and suggested references.
It isn't official material, and ISC2 hasn't reviewed or endorsed it. Never share real exam questions:
the candidate confidentiality agreement forbids it.
